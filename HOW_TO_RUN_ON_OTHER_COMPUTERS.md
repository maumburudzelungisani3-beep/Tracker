# 📁 How to Run on Any Computer (100% Portable & Silent)

This folder contains a **completely self-contained, portable version** of the Registry Office File Tracker.

The other computer **does NOT need Node.js, Git, Python, or any other software installed.**

---

## 🚀 Easy 3-Step Setup on Any Computer

### Step 1: Copy this Folder
Copy the entire `TRACKER` folder to the target computer:
* Via **USB flash drive**
* Or over your local network / shared folder.

---

### Step 2: (Recommended) Create Desktop Icons
Inside the `TRACKER` folder on the computer, double-click:
* **`Create-Desktop-Shortcut.bat`**

This places two shortcuts on the Desktop:
1. **Registry File Tracker** — Double-click to launch directly in your web browser with **NO command prompt window**.
2. **Stop Registry Tracker** — Double-click whenever you want to close the background services.

---

### Step 3: Launch & Use

* **Double-click `Launch-Silent.bat`** (or the **Registry File Tracker** desktop icon).
* **No command prompt window will stay open.** It runs silently in the background and opens the app straight in your web browser.
* It establishes a secure online link via Cloudflare and copies the link to your clipboard so you can open it on your phone or share it with colleagues.

---

## 🔄 Syncing with Your Online Excel / Google Sheet

Once the app opens in your browser:
* Click the **`🔄 Sync Online Sheet`** button in the top navigation bar.
* The system will automatically fetch the latest records from your online spreadsheet and update your database and dashboard immediately!
* You can also use **`📥 Import Excel / CSV`** to upload an `.xlsx` file from your computer anytime.

---

## 🛑 How to Stop
When you are done using the tracker:
* Double-click **`Stop-Tracker.bat`** (or the Desktop shortcut **Stop Registry Tracker**).
* This cleanly terminates the background services.
